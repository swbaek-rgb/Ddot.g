# Don't 땃쥐 me 🐭

Figma **Honnol** 파일의 '땃쥐' 섹션 디자인으로 만든 땃쥐 쓰다듬기 웹게임.
('째무 빗질하기' 게임 규칙 참고)

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. (빌드/서버 불필요)

모바일도 지원합니다 — 터치로 쓰다듬고, 세로로 들면 가로 모드 안내가 뜹니다.
디자인이 1440×1024 가로 화면이라 가로 모드 전용입니다.

## 규칙

- **Start**를 누르면 커서가 hand1로 바뀌고, 클릭/스페이스를 누르는 동안 hand2가 된다.
- **상태1 (한눈팔기)** — 클릭 또는 스페이스바를 누르고 있으면 점수가 누적된다. 길게 유지할수록 점수가 가속된다.
- **상태2 (고개 돌림, 위험!!)** — 슬슬 화나려는 상태. 이때도 쓰다듬으면 점수가 **2.5배**로 오르지만, 언제 상태3으로 넘어갈지 모른다.
- **상태3 (폭발 직전)** — 이때 0.01초라도 쓰다듬으면 즉시 게임오버. 상태2가 오는 박자는 불규칙하다.
- 시간이 지날수록 난이도가 오른다 — 한눈파는 시간과 경고 시간이 짧아지고, 폭발 확률이 높아진다(30초에 걸쳐 최고 난이도 도달).
- 쓰다듬는 동안 손 옆에 +00 득점이 떠올랐다 사라진다. 상태2 보너스 득점은 더 크게 표시된다.
- 최고 기록은 브라우저 localStorage에 저장된다(대시보드 버튼).

## 개발용

`index.html?debug=game1|game2|game3|over` 로 특정 화면을 강제 표시할 수 있다.

에셋(`assets/*.svg`)은 Figma Honnol 파일 '땃쥐' 섹션(node 103:406)에서 추출했다.
